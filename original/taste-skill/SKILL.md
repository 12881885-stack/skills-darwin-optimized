# Taste Skill — Anti-Slop 前端设计技能集

## 简介

防止 AI 生成千篇一律的"垃圾"界面，提供高质量设计感输出。

## 技能列表

| 技能 | 描述 |
|------|------|
| **taste-skill** | 默认全能款，高质量前端输出 |
| **gpt-taste** | 更严格的 GPT/Codex 版本，激进反垃圾 |
| **image-to-code** | 图生代码 pipeline |
| **redesign-skill** | 已有项目 UI 审计与修复 |
| **soft-skill** | 柔和高端 UI |
| **minimalist-skill** | 编辑器产品风（Notion/Linear 感） |
| **brutalist-skill** | ⚠️ BETA 瑞士机械风 |
| **output-skill** | 防半成品输出 |
| **brandkit** | 品牌工具包 |
| **imagegen-frontend-web** | 前端 web 图生参考 |
| **imagegen-frontend-mobile** | 移动端图生参考 |
| **stitch-skill** | 设计缝合技能 |

## 安装

```bash
npx skills add https://github.com/Leonxlnx/taste-skill
```

## 使用

生成前端代码时，可以引用对应 SKILL.md 的设计原则。技能文件位于本目录。

官网: https://tasteskill.dev
